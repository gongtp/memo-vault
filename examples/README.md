# 可导入的测试数据

[demo.vault.json](demo.vault.json) 是加密测试文件，主密码为 `a12345678`，仅包含虚构账号。

在初始页面选择“导入已有加密信息库”，选择该文件，输入密码一次，解密预览后确认导入。也可以先用初始密码进入空库，再在“设置与备份”导入。已有库导入会替换账号列表，请先备份。

| 平台 | 登录名 | 测试账号密码 | 用途 |
| --- | --- | --- | --- |
| GitHub（测试） | demo@example.com | demo-github-123 | 查看、复制、编辑、备份 |
| Notion（测试） | notion@example.com | 无，Google 登录 | 第三方登录、空密码 |
| 生活账号（测试） | demo_life | demo-life-456 | 搜索、分类、收藏 |

验证步骤：

1. 导入后默认关闭“操作前再次验证”，可直接查看和复制密码。
2. 在设置开启该开关，再查看或复制时要求输入当前主密码。
3. 切到后台后返回，需要重新解锁；设置值保留。
4. 在设置修改主密码，新密码输入一次。锁定后旧初始密码失效。
5. 导出新加密文件，在另一设备导入，用导出时的主密码恢复。

如果导入到已有库，仍使用已有库的主密码解锁，不会将其重置为测试文件密码。此文件不在 `npm run build` 的 Pages 产物中。可运行 `node tests/create-browser-fixture.mjs` 重新生成。
