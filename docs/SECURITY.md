# Memo Vault v0.4 安全实现与验证

此版本使用本地加密存储。首次打开为空库，公开初始密码为 a12345678，输入一次即可初始化并解锁。已存在的库仅接受自己的当前密码，不会回退到初始密码。当前实现使用原生 ES Modules，支持 PWA 离线应用缓存；Vue 工程迁移未实施，远程发布需部署构建产物。

## 已实现的保护

- 主密码：首次使用公开初始密码，进入后在设置中修改，新密码输入一次、8 至 1024 字符，不裁剪空格。公开初始密码不是个人数据的安全保障，应在录入个人信息前修改。初始密码常量随程序发布，不作为已有库的解锁后门。个人主密码和密码哈希不持久保存，遗忘后无找回功能。
- 修改密码：在已解锁会话内重新生成盐与密钥，原子地重新加密全部数据和设置；提交成功后才替换会话密钥。保存失败保留原库和原密码。旧导出文件使用旧密码，不被追溯修改。
- 本地数据：IndexedDB 的 memo-vault-secure 数据库保存按模块组织的单条事务记录。账号保存为加密封包；笔记未锁定时为本地结构化明文，开启锁定后为独立加密封包。账号关闭模块锁定时还会存储不可导出的设备解锁密钥。平台名、登录名、密码、备注、分类等全部包含在密文中。
- 加密：Web Crypto API，PBKDF2-SHA-256、600,000 次迭代、16 字节随机盐，派生不可导出的 AES-256-GCM 密钥。每次写入生成独立的 12 字节随机 IV，认证标签 128 位。版本、算法、盐、IV、派生参数和修订标记作为认证附加数据。
- 解锁：使用输入的主密码派生密钥并验证 GCM 认证标签。错误密码、篡改文件或不支持的版本不替换原数据。
- 操作验证：新库默认关闭，解锁后可直接显示/复制密码及编辑账号。配置中可开启“操作前再次验证”，这些操作以及删除账号、修改主密码前就会验证。删除无论开关状态均额外展示确认弹窗，取消不写入。关闭开关仅改变解锁后的操作流程，不关闭受保护模块的解锁、自动锁定、账号本地或导出加密。开关本身在密文内保存，随导入导出迁移；旧文件没有设置时按开启处理。密码显示 30 秒后隐藏，导航、搜索、排序和切换账号时隐藏。
- 复制：开关关闭时单击复制；开启时先验证成功，再主动点击一次“复制密码”，兼容 Safari 对用户手势的要求。授权限当前账号、当前会话、30 秒内一次有效，取消即失效。应用不承诺自动清除系统剪贴板。
- 自动锁定：visibilitychange 进入隐藏状态、pagehide、BFCache 恢复均锁定。前台 5 分钟闲置锁定；定时器被系统暂停时，下一次交互也会检查期限。锁定清除界面内容、表单、解密账号、内存密钥引用、导入预览和操作授权；返回前台只有受保护模块需要重新解锁，未锁定笔记及概览、设置仍可使用。
- 异步防护：解锁、验证、保存和导入都校验会话代次，防止锁定后异步操作重新显示数据。已提交到 IndexedDB 的写入可能完成，但不会让页面重新解锁。
- 写入：串行加密保存，IndexedDB 事务完成才报告成功。修订标记在同一写事务中比较；发现另一页面修改后拒绝覆盖并锁定。BroadcastChannel 同步通知其他页面锁定。
- 输入：记录作为文本转义渲染，网站只接受 HTTP/HTTPS，导入限制文件大小、条数、字段、格式和 KDF 上限。通过 CSP 限制脚本、Worker、manifest 和连接到本源，以支持离线程序下载；不引入第三方脚本/字体/分析服务。

## 加密导入导出

分类与登录方式的选项列表在密文中的 options 字段保存，默认项与自定义项都可增删。每组最多 100 项，名称为 1 至 40 字符，不允许同组重名。已有账号使用的选项不可删除，界面和存储层均检查引用；必须先修改相关账号，不自动替换或清空引用。不使用任何分类/方式的账号可显示为未分类/未设置，空选项列表作为有效配置保留。旧数据没有 options 字段时迁移为默认选项；所有保存、删除、修改主密码和导入导出均保留选项配置。

导出为 memo-vault-backup-时间.json，外层 type=memo-vault-backup、version=1，modules.accounts 为认证加密封包（账号、选项、设置），modules.notes 为普通 JSON（笔记、标签、归档、回收站）。账号密文内部 noteData 为空，不再重复保存笔记。文件不包含明文账号、主密码或设备密钥。笔记不受导出加密保护，即使本地开启笔记锁定，备份笔记仍可直接阅读和编辑；笔记格式合法的修改可以导入，账号部分的篡改会被认证校验拒绝。

新设备导入：先验证本设备主密码（新建时为公开初始密码），选择文件 → 输入文件主密码 → 解密验证 → 预览数量 → 确认替换。保留本设备主密码和模块锁定设置。

已有信息库导入：先解锁当前库 → 选择文件并验证文件密码 → 预览并确认整库替换。数据和操作验证设置重新使用本设备密钥加密，本设备主密码不变，是否仍在使用初始密码的状态保留本设备的值。导入、取消或保存失败不静默覆盖当前信息库。旧版未加密的演示 JSON 不再支持。

原文件选择器、系统分享菜单或其他应用可能使页面进入后台；一旦收到隐藏事件就锁定，不绕过这条规则。若系统选择文件时使当前库锁定，先重新解锁再继续导入。此交互和 iOS 独立窗口仍需真机验收。

## 发布与运行

npm run build 将白名单中的 16 个应用文件输出到 dist/，其中 sw.js 由构建注入文件摘要与版本号。GitHub Pages 应发布这个目录，不发布仓库根目录、测试、截图、文档或个人备份。构建中遇到未知产物会失败，避免误带文件。HTTP localhost 可开发，远程必须 HTTPS。

离线缓存仅包含白名单中的静态程序文件，不读取 IndexedDB，不缓存账号、笔记、主密码、备份或任意请求。每个文件下载时核对构建摘要，全部成功才完成安装；失败保留旧版本。新版等待旧窗口全部关闭后启用，不强制刷新编辑页。缓存清理仅针对同一应用路径的历史程序缓存，不删除数据库或其他站点缓存。离线准备失败不会重置现有信息库。使用步骤见 [OFFLINE.md](OFFLINE.md)。

浏览器存储不是永久备份，清理网站数据或设备丢失后只能使用已有备份文件和账号部分对应主密码恢复。Safari 与主屏幕 App 的本地库可能独立，推荐在主屏幕 App 中创建或导入。

## 验证范围与限制

npm run check 覆盖加密往返、错误密码、认证头/密文篡改、随机盐和 IV、不可导出密钥、跨设备恢复、本地主密码保持、存储失败、并发冲突、锁定后的异步失效和前后台生命周期。

自动化测试不等于独立安全审计。加密主要保护锁定状态及备份；解锁后明文必须进入程序内存。JavaScript 不能保证立即擦除物理内存，也无法防止被篡改的应用代码、恶意扩展、系统或设备被控制时读取信息。账号确认删除后从当前库永久移除，账号回收站尚未实现；文档不提供归档和回收站，删除前确认后直接移除。既有导出备份不会随删除操作更新。

## 笔记模块

笔记标题、块内容、勾选状态、标签、日期、置顶、归档和回收站按笔记模块策略保存：未开启锁定时为本地结构化明文，开启后为独立密文。新备份只加密账号，笔记导出普通 JSON，本地笔记锁定不改变导出规则。未保存草稿与编辑历史只驻留内存。笔记以文本渲染，不接收 HTML。所有模块在同一写入队列中构造当前快照，账号修改、选项/设置修改和更换主密码均保留笔记。

外层加密封包仍为 version 1；内部 schemaVersion 升至 2，读取内部 version 1 时补空笔记。旧客户端拒绝新的内部格式，避免静默丢弃笔记。旧备份导入保持整库替换，预览明确提示清空当前笔记；旧归档和回收站笔记在导入时恢复为普通文档，保留内容，不执行过期清理。

自动保存停止输入约 600 毫秒触发，持续输入最多约 3 秒触发一次快照；组合输入结束后再保存，避免打断中文输入法。只有事务成功后显示已保存。切后台仍立即清空界面和会话引用，正在进行的已提交写入可能完成，未提交输入可能丢失。会话代次检查阻止旧回调回显内容或影响重新解锁后的编辑。

开启操作验证时，打开已有笔记、复制、删除和标签管理需要验证；同一编辑过程自动保存不重复验证。列表中的标题和摘要与账号列表一样在解锁后可见。复制全文通过单独按钮维持用户手势。锁定销毁笔记对话框及授权。

新增测试覆盖账号/笔记交错写入、密码修改保留双方数据、真实旧版示例迁移、完整备份恢复、标签关联、容量/字段校验、保存失败重试、并发冲突、锁定时写入、回收站期限及清理失败保护。手机视口检查不能替代真实 iPhone 软键盘和主屏幕模式测试。

## 模块锁定实现

`module-vault.mjs` 管理当前应用的模块会话，`vault.mjs` 提供加密格式、校验及旧库兼容能力。账号默认受保护，笔记默认直接访问。模块开关属于本设备策略，切换必须验证主密码，并在单条 IndexedDB 记录中原子完成明文/密文转换与密钥增删，失败不替换原数据。旧加密库在首次验证后迁移，迁移前不会将旧笔记当作空库覆盖。

两个受保护模块使用同一个主密码、不同随机盐和派生密钥。取消账号锁定时持久保存账号 CryptoKey（不可导出），使重开后的免密访问成为可能；这种模式对本设备访问者不提供主密码屏障。该密钥不能解密受保护笔记。重新开启账号锁定后从记录中删除设备密钥。关闭笔记锁定后笔记在本地不再加密。导出时账号使用主密码派生密钥加密，笔记始终为普通 JSON，不导出设备密钥。

锁定清除受保护模块的内存数据和访问授权；未保护笔记使用独立会话代次，后台锁定不取消其普通保存。跨页更新重新读取数据库并撤销旧授权，修订冲突拒绝覆盖。统一改密以单次事务更新账号、受保护笔记与必要的设备密钥；旧备份不变。导入沿用目标设备的开关及主密码，账号、笔记和策略一起提交。
## 分模块 JSON 备份兼容

新解析器先验证外层格式、版本、模块是否齐全及笔记结构，再使用文件主密码认证账号密文。预览和确认后，账号与笔记仍以一个 IndexedDB 事务提交；坏密码、非法标签引用、缺少模块、错误版本、存储失败或冲突都不会覆盖原数据。新 JSON 文件输入/输出上限为 32 MB，账号密文本身仍受原有约 5 MB 限制。未加密笔记不占用账号密文容量，已覆盖超过 5 MB 的笔记往返测试。本地受保护笔记仍有独立加密容量限制。

旧 type=memo-vault-encrypted 的整库加密备份继续按旧流程解密并恢复其中的笔记；旧版明文演示格式仍拒绝。普通笔记模块不会获得账号密文的认证保护，这是可编辑普通 JSON 的预期行为。
## 普通文档编辑器

当前界面是标题与整篇连续正文，不再提供分块编辑、归档或回收站。自动保存沿用事务完成确认与代次防护。新正文仍映射到兼容的 blocks 结构；旧清单和项目列表在正文中以文本符号保留，不接受 HTML。未编辑正文时不重写已有块结构，仅修改标题不会破坏旧正文。

旧 archivedAt/deletedAt 标记在迁移、载入或导入后清空，相关内容恢复到普通文档列表，不再自动过期删除。新文档删除直接调用同一写队列中的 deleteNote，只有额外确认后执行；提交失败保留原文档，成功后从当前库移除。历史备份不变。旧 VaultSession 的归档/回收站方法仅保留为旧格式兼容实现，当前应用不使用。

## 表格文档

表格作为笔记的可选 table 字段保存，读取、写入和导入统一验证列类型、唯一编号、计算列引用、日期、数字及容量。计算列不信任导入的计算结果，每次按引用列和白名单运算符重新计算；不执行任意代码，引用限于数字和金额输入列，禁止循环或计算列间引用。旧计算列未指定运算符时仍按乘法读取。旧普通文档不新增字段或改写正文。含表格备份使用外层 version 2，防止旧客户端导入时静默丢失表格；新客户端兼容旧 version 1 和旧加密整库格式。表格默认本地明文，开启笔记保护后随笔记加密；导出仍为可读 JSON。
