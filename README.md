# Memo Vault

个人账号信息库 v0.3。已实现账号新增/编辑/删除、初始密码解锁、主密码修改、可配置的操作前验证、IndexedDB 加密持久化、后台与闲置自动锁定，以及跨设备加密导入导出。详情中点击删除后需核对账号并确认；取消不更改数据，确认后永久删除并加密保存，旧备份不受影响。

运行 `npm run dev`，打开 http://127.0.0.1:4173 。需要 Node.js 22+，无需安装第三方依赖。`npm run check` 执行语法检查和安全功能测试，`npm run build` 生成仅包含程序文件的 `dist/`。

预览服务监听 `0.0.0.0:4173`，启动时打印 Network 局域网地址。同一局域网设备可以访问页面；默认不修改防火墙；只有确认连接被拦截时，再由用户决定是否放行。局域网 HTTP 不属于安全上下文，Web Crypto 解锁需要可信 HTTPS（例如发布后的 GitHub Pages），不能通过关闭操作验证绕过。预览仅允许访问应用文件，不提供项目文档、测试或个人备份的目录服务。

安全实现、验证与限制见 [docs/SECURITY.md](docs/SECURITY.md)。长期规划见 [docs/PLAN.md](docs/PLAN.md)，以安全说明中的已实现状态为准。当前保留原生模块实现，Vue/TypeScript 迁移仍是后续工程规划。iPhone 主屏幕模式需要真机验收，尚未完成独立安全审计。

数据仅加密保存在当前浏览器。导出文件后可以在另一设备导入并使用文件的主密码恢复；已有库导入时保留本设备主密码。整库替换，不自动合并或同步，不接受旧明文演示文件。请定期导出加密备份，并在清理网站数据之前确认可恢复。

首次使用为空库，输入公开初始密码 `a12345678` 一次即可进入。进入后可在“设置与备份”修改主密码，新密码只输入一次、至少 8 个字符。修改成功后初始密码不能再解锁；既有信息库不会被更新或默认密码重置。初始密码公开，录入个人信息前请先修改。

“操作前再次验证”默认关闭，解锁后可直接查看、复制密码和编辑账号；开启后这些操作再验证一次。开关加密保存在信息库中，并随导出文件迁移。无论是否开启，本地与导出始终加密，启动仍需解锁。查看 30 秒后自动隐藏，切到后台立即锁定，前台闲置 5 分钟锁定，未保存编辑会被丢弃。旧版库缺少此设置时保留原先“再次验证开启”的行为。

测试文件：[examples/demo.vault.json](examples/demo.vault.json)，导入密码 `a12345678`，包含三个虚构账号，说明见 [examples/README.md](examples/README.md)。测试文件单独提供，不进入 Pages 构建产物。修改主密码后请重新导出；之前导出的文件仍使用旧密码。

GitHub Pages 发布目录应为 `dist/`，不含个人数据、测试和设计截图。当前尚未创建远程仓库、发布 Pages 或启用 PWA 离线安装。

新增/编辑账号时，点击“所属分类”或“登录方式”旁的“管理”可添加、删除选项。默认项与自定义项地位相同，均可删除。已有账号正在使用的选项不可删除，必须先修改相关账号；不会自动替换或修改账号。没有使用中的引用时支持删除全部选项，空列表不会自动恢复默认值。选项列表在信息库内加密保存并随备份迁移，旧文件会自动补齐原有默认列表。
