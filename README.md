# Memo Vault

个人信息库 v0.4。提供账号管理与日常笔记，使用同一个主密码，按模块配置是否需要解锁。账号新增/编辑/删除、选项管理、主密码修改、操作前验证、后台与闲置锁定和跨设备加密备份继续保留。账号删除仍需核对并确认，确认后永久删除；文档确认后直接删除，不提供回收站。

## 普通文档

笔记现在采用普通文档编辑方式：标题下方是连续正文，按回车换行、空行分段，打开已有文档默认阅读，点击“编辑”后修改；点击“完成”保存成功后返回阅读。没有段落类型、逐块添加、归档或回收站。文档信息（日期、可选标签）收在页面底部，支持搜索、标签筛选和最近编辑排序。撤销和重做仅作用于当前编辑过程。

停止输入约 600 毫秒后自动保存，连续输入最长约 3 秒触发快照；中文输入法组合期间延后。返回列表、切换模块或导出前等待保存，数据库提交后显示「已保存到本机」。保存失败保留编辑内容并支持重试。受保护文档切后台时锁定；未开启保护的文档仍可使用。

删除文档必须确认，确认后直接删除，应用内无法恢复；旧备份不变。旧版归档和回收站里的文档在加载或导入时统一恢复为普通文档，保留正文、标签和日期，不执行 30 天自动清理。旧列表和清单以普通正文中的 •、☑、☐ 显示，勾选状态保留。

账号导出加密，文档正文和标签在同一个备份文件里保存为普通 JSON。账号及本地受保护文档仍受约 5 MB 加密容量限制，整个 JSON 备份上限为 32 MB。文档仍限制每篇标题 100 字、正文合计 20,000 字；不支持图片附件、云同步或富文本排版。
## 运行与数据

运行 `npm run dev`，打开 http://127.0.0.1:4173 。需要 Node.js 22+，无需安装第三方依赖。`npm run check` 执行语法检查和安全功能测试，`npm run build` 生成仅包含程序文件的 `dist/`。

预览服务监听 `0.0.0.0:4173`，启动时打印 Network 局域网地址。同一局域网设备可以访问页面；默认不修改防火墙；只有确认连接被拦截时，再由用户决定是否放行。局域网 HTTP 不属于安全上下文，Web Crypto 解锁需要可信 HTTPS（例如发布后的 GitHub Pages），不能通过关闭操作验证绕过。预览仅允许访问应用文件，不提供项目文档、测试或个人备份的目录服务。

安全实现、验证与限制见 [docs/SECURITY.md](docs/SECURITY.md)。长期规划见 [docs/PLAN.md](docs/PLAN.md)，以安全说明中的已实现状态为准。当前保留原生模块实现，Vue/TypeScript 迁移仍是后续工程规划。iPhone 主屏幕模式需要真机验收，尚未完成独立安全审计。

数据仅保存在当前浏览器：账号始终加密；笔记默认不加密，开启模块锁定后加密。导出一个普通 JSON 文件，账号模块加密，笔记模块（包括标签、归档和回收站）为可读 JSON；笔记本地锁定开关不改变导出格式。另一设备先用本机主密码验证，再输入文件主密码导入；保留本设备的主密码和模块锁定开关。整库替换，不自动合并或同步，不接受旧明文演示文件。请定期导出 JSON 备份，并在清理网站数据之前确认可恢复。

首次使用为空库，直接进入概览和未锁定的笔记。账号默认需要公开初始密码 `a12345678` 解锁。进入后可在“设置与备份”修改主密码，新密码只输入一次、至少 8 个字符。修改成功后初始密码不能再解锁；既有信息库不会被更新或默认密码重置。初始密码公开，录入个人信息前请先修改。

“操作前再次验证”默认关闭，解锁后可直接查看、复制密码和编辑账号；开启后这些操作再验证一次。开关加密保存在信息库中，并随导出文件迁移。账号本地和导出始终加密，笔记导出为普通 JSON，是否进入模块需要密码由模块开关控制。查看 30 秒后自动隐藏，切到后台立即锁定，前台闲置 5 分钟锁定，未保存编辑会被丢弃。旧版库缺少此设置时保留原先“再次验证开启”的行为。

测试文件：[examples/demo.vault.json](examples/demo.vault.json)，导入密码 `a12345678`，包含三个虚构账号，说明见 [examples/README.md](examples/README.md)。测试文件单独提供，不进入 Pages 构建产物。修改主密码后请重新导出；之前导出的文件仍使用旧密码。

GitHub Pages 发布前运行 `npm run build`，发布生成的 `dist/`，不含个人数据、测试和设计截图。已支持 PWA 离线缓存及主屏幕图标；不要直接发布源码根目录，其中的 Service Worker 是待构建模板。iPhone 添加到主屏幕后，保持联网从桌面图标打开一次，等该窗口显示「离线已就绪」再断网使用。完整步骤与验收清单见 [离线使用与部署](docs/OFFLINE.md)。

新增/编辑账号时，点击“所属分类”或“登录方式”旁的“管理”可添加、删除选项。默认项与自定义项地位相同，均可删除。已有账号正在使用的选项不可删除，必须先修改相关账号；不会自动替换或修改账号。没有使用中的引用时支持删除全部选项，空列表不会自动恢复默认值。选项列表在信息库内加密保存并随备份迁移，旧文件会自动补齐原有默认列表。

## 按模块锁定

设置中的「需要解锁的模块」分别控制账号和笔记：账号默认开启，笔记默认关闭。调整保护开关必须验证统一主密码。概览和设置可直接访问；修改保护、主密码、操作验证、导入导出等管理操作需要验证主密码。旧版整库首次验证后原子迁移，账号、旧文档和标签内容保留，旧归档/回收站记录恢复为普通文档，迁移失败保留原库。

账号关闭模块锁定时，IndexedDB 会保存不可导出的设备解锁密钥，以支持重开后免密进入；账号密文格式不变，但此模式不能防止拥有本设备访问权的人读取账号。重新开启会删除持久保存的解锁密钥。笔记关闭锁定时以结构化数据保存在本地；开启时使用同一主密码、独立随机盐和密钥加密，账号的设备密钥不能解密受保护笔记。所有本地转换使用单次 IndexedDB 事务提交。后台或闲置超时仅清除受保护模块的授权，未锁定笔记可继续使用。

新备份为 memo-vault-backup-时间.json，外层 type 为 memo-vault-backup、version 为 1。modules.accounts 保存加密封包（含账号、选项及设置），modules.notes 保存普通笔记 JSON（含 notes、tags），不导出设备密钥。模块开关信息在账号密文设置内保存；导入采用目标设备的开关和主密码。旧 memo-vault-encrypted 整库备份继续支持导入，旧客户端不支持新格式。修改统一主密码会同时更新账号和受保护笔记，旧备份继续使用旧密码。

## 表格文档

新建直接进入空白文档；插入的表格从“名称、内容”两列开始，可自定义列名、修改兼容的列类型、增加文本/数字/金额/日期/计算列，并为数字或计算列开启求和。计算列选择两个数字或金额列进行加、减、乘、除，可随时修改引用和运算；无需编写公式。适用于费用、工时、库存、得分等记录。已有购买记录表格继续保留，原计算列按乘法读取，可改成其他运算。

每表最多 12 列、500 行，单元格最多 500 字；数字最多 9 位整数、2 位小数。计算采用整数定点运算，结果四舍五入到两位小数；除零显示错误，原始记录仍可保存。手机表格可横向滑动，合计同时显示在表格下方。支持增删行列和编辑过程撤销；暂不支持手写任意公式、计算列之间引用或 Excel 文件导入导出。

表格沿用笔记的离线、模块保护和自动保存策略，搜索及复制全文包含表格内容。包含表格时，导出文件外层版本为 2，需使用新版应用导入；没有表格时仍导出版本 1。旧版加密备份和版本 1 的 JSON 备份继续兼容，导入仍是整库替换。表格同普通笔记一样以可读 JSON 导出，本地是否加密由笔记模块保护开关决定。

普通文档与表格统一默认进入阅读模式：标题和正文/单元格均以静态文本展示，阅读页提供返回、编辑、更多文档操作及表格展开入口，不展示撤销、重做、文档信息、行列管理等编辑控件。新建文档直接进入编辑，编辑中的自动保存保持不变；点击完成会等待保存，失败时保留编辑内容并提示重试。

## 文字与表格混排

编辑工具栏统一使用“插入表格”，在最近的文字光标处插入；没有光标时追加到末尾。表格前后可直接输入文字，不再重复显示添加按钮和内容段编号，移除表格收进其“•••”菜单。一篇文档最多 60 个内容段、20 张表格，文字合计 20,000 字。多个表格独立设置列和计算；编辑时每张表格均可直接填写，工具栏随当前单元格切换。阅读模式连续展示全文，无插入或设置工具。旧普通文档和单表格文档在首次插入内容时转换，保留原文字和表格；不主动批量重写已有数据。

含混合内容的备份使用 version 3，需新版导入；新版继续兼容 version 1、2 及旧加密备份。导出文字、表格仍遵循笔记普通 JSON 规则。



### 手机文档编辑

新建直接进入空白文档；阅读时点击“编辑”，右上角“完成”回到阅读。编辑工具固定在手机底部并根据可视视口避让键盘：正文时显示撤销、重做和“插入表格”；选中单元格后显示上一格、下一格、加行、加列、计算和更多操作。表格单元格直接填写，表格前后直接写文字，列标题可打开设置。计算面板可一键开启数字合计；非数字内容转换失败时保留原数据。复杂计算列仍支持加减乘除。阅读和编辑均可展开表格，编辑展开时固定表头，收起后返回原文档位置。已有文档不会批量迁移，旧单表格仅在周围输入文字或插入新表格时转为混排。

账号与笔记列表每页显示 10 条，支持上一页、下一页及页数/总数提示。搜索和筛选始终针对全部记录，再对结果分页；变更搜索、筛选或排序回到第一页，末页删除后自动回到有效页。页码仅为会话界面状态，不写入存档或备份。
